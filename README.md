# Infraestrutura como Código (IaC) - Script de Criação de Estrutura

Projeto prático desenvolvido para o desafio de Infraestrutura como Código (IaC) da Digital Innovation One (DIO).

## 📌 Descrição do Projeto
Este projeto contém um script em Shell (`iac1.sh`) para automação da infraestrutura em ambiente Linux. O script realiza a criação de diretórios, grupos de usuários, contas de usuários com senhas criptografadas e atribui as permissões corretas de acesso a cada pasta.

## 🛠️ Estrutura Criada pelo Script
- **Diretórios**: `/publico`, `/adm`, `/ven`, `/sec`
- **Grupos**: `GRP_ADM`, `GRP_VEN`, `GRP_SEC`
- **Usuários**:
  - Administração: `carlos`, `maria`, `joao`
  - Vendas: `debora`, `sebastiana`, `roberto`
  - Secretariado: `josefina`, `amanda`, `rogerio`
